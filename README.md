
# data-gatherer-bukkit

A library for gathering user input in a step-based process.

## 📦 Installation

### Gradle (Kotlin DSL)
```kotlin
repositories {
    maven("https://jitpack.io")
}

dependencies {
    implementation("com.github.Drownek:data-gatherer-bukkit:2.0.1")
}
```
### Gradle (Groovy)
```groovy
repositories {
    maven { url 'https://jitpack.io' }
}

dependencies {
    implementation 'com.github.Drownek:data-gatherer-bukkit:2.0.1'
}
```
### Maven
```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependencies>
    <dependency>
        <groupId>com.github.Drownek</groupId>
        <artifactId>data-gatherer-bukkit</artifactId>
        <version>2.0.1</version>
    </dependency>
</dependencies>
```
